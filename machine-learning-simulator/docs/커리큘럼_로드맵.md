# EduinoAI · Machine Learning Simulator — 커리큘럼 / 제작 로드맵 (1차)

> **목적**: 대학생 ML **이론 수업**을 효과적으로 돕는 인터랙티브 시뮬레이터.
> **핵심 방식**: 사용자가 직접 데이터·조건을 **입력/추가/삭제**하면, 모델의 **학습 과정과 결과가 실시간으로** 변하는 것을 보며 이론을 체득한다. (각 모듈에 대표 예시 1개 기본 탑재)
> 기준일 2026-06-30 · 본 문서는 1차 계획안(수정 가능).

---

## 0. 제품 개요
- **대상**: 대학 학부/교양 ML·데이터과학 수강생, 강의 시연용.
- **형태**: 웹(브라우저), 데스크톱 우선. 강의 중 빔프로젝터 시연 + 학생 개별 실습.
- **차별점**: 공식 암기가 아니라 **"조건을 바꾸면 학습이 어떻게 달라지는가"**를 손으로 만지며 이해.
- **교육 원칙**:
  1. 모든 알고리즘은 **직접 구현(from scratch)** — 내부가 보여야 이론 교육이 된다(블랙박스 금지).
  2. 화면 = **데이터 · 학습과정 · 이론(손실/경사/가중치/수식)** 을 동시에.
  3. **한 스텝씩(step)** 실행으로 반복(iteration) 단위 관찰 가능.
  4. 하이퍼파라미터·데이터를 **실시간 토글** → 즉각 재학습.

## 1. 공통 아키텍처 (모든 모듈 공유 — 가장 먼저 제작)
```
┌──────────────────────────────────────────────────────────┐
│  상단: 모듈 탭(선형회귀 · 분류 · 신경망 · 군집 …) · 데이터셋 프리셋   │
├───────────────┬──────────────────────────┬───────────────┤
│ 데이터 캔버스   │   학습 시각화(메인)         │  컨트롤 패널     │
│ (클릭=추가      │  결정경계/회귀선/군집 +     │ 하이퍼파라미터   │
│  우클릭=삭제     │  실시간 업데이트            │ 슬라이더·토글    │
│  드래그=이동)    │                          │ [학습][스텝][리셋]│
├───────────────┴──────────────────────────┴───────────────┤
│ 하단 이론 패널: 손실곡선 · 가중치/파라미터 · 수식 · 지표(정확도 등)  │
└──────────────────────────────────────────────────────────┘
```
- **DataLab(공통)**: 점 추가/삭제/이동, 라벨 토글, 프리셋(예시) 로드, 노이즈·정규화.
- **Trainer 인터페이스**: 모든 모델이 `init / step / predict / loss / params` 구현 → 셸은 동일하게 구동.
- **Plot 유틸(Canvas)**: 산점도·결정경계(격자 평가)·손실곡선·등고선 — 직접 구현(라이브러리 X).
- **수식 렌더**: 경량 처리(필요 시 KaTeX(무료) 도입 검토).

## 2. 커리큘럼 (기초 → 심화)

### 🟢 LEVEL 1 — 기초 (지도학습·최적화의 토대)
| # | 모듈 | 학습 목표(이론) | 사용자 입력/조작 | 실시간 시각화 |
|---|---|---|---|---|
| M1 | **선형 회귀 + 경사하강** | 비용함수 J(θ), 경사하강, 학습률·수렴 | (x,y) 점 추가/삭제, 학습률·반복 | 회귀선 피팅 + **J(θ) 등고선·하강 경로** + 손실곡선 |
| M2 | **다항 회귀 · 과적합 · 정규화** | 편향-분산, 과적합/과소적합, Ridge/Lasso | 차수, λ, 노이즈, 데이터 수 | 곡선 변화 + **훈련 vs 검증 오차** |
| M3 | **로지스틱 회귀(이진 분류)** | 시그모이드, 교차엔트로피, 결정경계 | 2클래스 점, 학습률, L2 | 확률 등고선 + 경계선 + 손실 |

### 🔵 LEVEL 2 — 중급 (대표 분류기·비지도 입문)
| # | 모듈 | 학습 목표 | 입력/조작 | 시각화 |
|---|---|---|---|---|
| M4 | **kNN** | 사례기반학습, k의 영향, 거리척도 | 점, k, 거리(L1/L2) | 경계 모양 변화 |
| M5 | **결정트리** | 엔트로피/지니, 분할, 깊이·과적합 | 점, 최대깊이, 기준 | 트리 + 영역 분할 |
| M6 | **K-평균 군집** | 비지도, 센트로이드, 수렴·지역최솟값 | 점, K, 시드 | 센트로이드 이동·군집 색 |
| M7 | **SVM** | 마진 최대화, 서포트벡터, 커널트릭 | 점, C, 커널(선형/RBF) | 마진·서포트벡터·비선형 경계 |

### 🟣 LEVEL 3 — 심화 (신경망·차원축소·최적화)
| # | 모듈 | 학습 목표 | 입력/조작 | 시각화 |
|---|---|---|---|---|
| M8 | **신경망(MLP)+역전파** | 은닉층·활성함수·역전파, 비선형 분리 | 데이터+점, 층/뉴런/활성/학습률 | 비선형 경계 형성 + 뉴런별 표현 + 손실 |
| M9 | **PCA(주성분분석)** | 분산 최대 축, 차원축소, 투영 | 점(2D/고차원 프리셋) | 주축·분산설명률·투영 |
| M10 | **경사하강 비교** | SGD·Momentum·Adam, 학습률·지형 | 손실 지형 선택, 옵티마이저 | 각 옵티마이저 하강 경로 비교 |
| (선택) | GMM·EM / DBSCAN / 교차검증 | 확률·밀도 군집, 일반화 평가 | — | — |

## 4. 제작 로드맵 (Phase 순서)
- **Phase 0 · 공통 셸**: DataLab(점 입력) + Trainer 인터페이스 + Plot 유틸 + 이론 패널 + 모듈 탭 골격. *(이게 끝나면 모듈 추가가 빨라짐)*
- **Phase 1 · LEVEL 1**: M1 → M2 → M3 (기초, 가장 중요)
- **Phase 2 · LEVEL 2**: M4~M7
- **Phase 3 · LEVEL 3**: M8~M10
- **Phase 4 · 마감**: 프리셋 데이터셋, 강의 모드(설명 오버레이), 반응형, 접근성, 배포

각 모듈 "완료" 정의: 사용자 데이터 입력 → 하이퍼파라미터 조절 → 학습/스텝/리셋 → 손실·경계·수식 실시간 반영 · 누수 없음 · 대표 예시 1개 탑재.
