# EduinoAI · Machine Learning Simulator — 커리큘럼 / 제작 로드맵 (2차)

> **무엇을 만드나**: "머신러닝이란?" 부터 차근차근 **설명 → 간단 체험 → 시뮬레이터 → 퀴즈**로 이어지는,
> ML을 **쉽고 재미있게** 이해시키는 **인터랙티브 학습 프로그램**. (대학 이론 수업 + 자기주도 학습 겸용)
> 핵심: 사용자가 데이터·조건을 **직접 입력/추가/삭제**하며 **학습 과정·결과가 실시간으로 변하는 것**을 보고,
> 매 단계 **개념·체험·퀴즈**로 내용을 풍부하게 담는다.
> 기준일 2026-06-30 · 2차 계획안(1차에서 "학습 프로그램"으로 확장).

---

## 0. 제품 개요
- **대상**: 대학 학부/교양 수강생(주), ML 입문자·자기학습자(겸). 강의 시연 + 개별 실습.
- **목표 경험**: "어렵고 수식뿐"이 아니라 **만지면서 이해** → 직관 → 그 다음 수식·이론.
- **3축**: ① 친절한 **개념 설명** ② 손으로 만지는 **체험/시뮬** ③ 즉시 피드백 **퀴즈** + 진척/보상.
- **마스코트(선택)**: 안내 캐릭터가 설명·격려(재미 요소). EDDIE 톤 재활용 가능.

---

## 1. 레슨 학습 루프 (모든 레슨 공통 구조)
각 레슨 = 아래 5스텝. 콘텐츠는 **데이터(JSON/모듈)로 정의** → 레슨 추가가 쉬움.
```
① 개념(Concept)   친절한 설명 + 비유 + 그림/애니. "왜?"부터.
② 체험(Quick Try) 1분 미니 인터랙션으로 직관 잡기(낮은 진입장벽).
③ 시뮬(Simulator) 데이터·하이퍼파라미터를 만지며 깊이 탐구(핵심).
④ 퀴즈(Quiz)      이해 확인 + 즉시 해설 피드백.
⑤ 정리(Recap)    한 줄 요약 + 다음 레슨/뱃지.
```
- 강의 모드: ②③을 강사가 시연, 학생은 같은 화면을 개별 실습.

## 3. 공통 아키텍처 (먼저 만드는 엔진)
- **LessonEngine**: 레슨 데이터(개념/체험/시뮬/퀴즈)를 받아 5스텝 루프 구동 + 네비게이션.
- **콘텐츠(데이터 주도)**: `content/ch0/lesson-0-1.js` 형식 — 텍스트·이미지·체험위젯·시뮬키·퀴즈문항. **레슨 추가 = 파일 추가**.
- **SimulatorShell**: 데이터 캔버스(점 추가/삭제/이동) + 컨트롤 + 학습 시각화 + 이론 패널([학습][스텝][리셋]).
- **Trainer 인터페이스**: 모든 모델 `init/step/predict/loss/params` → 셸이 동일하게 구동(from scratch 구현).
- **QuizEngine**: 객관식/참거짓/슬라이더예측, 즉시 해설.
- **Progress**: 레슨 완료·퀴즈 점수·뱃지(localStorage), 진행률 바.
- **Plot 유틸(Canvas)**: 산점도·결정경계·손실곡선·등고선 직접 구현.
- **마스코트/설명 오버레이**(선택): 단계별 가이드.

---

## 4. 게이미피케이션 (재미 요소)
- 레슨/챕터 **진행률 바 + 완료 체크 + 뱃지**(예: "경사하강 마스터").
- 퀴즈 **즉시 정답/해설 + 점수 + 콤보**.
- 체험 미니게임(선 맞추기 등) **점수·랭킹(localStorage)**.
- 마스코트 격려 멘트, 수료증.

## 5. 기술 스택 (고정)
바닐라 JS(ESM) · Vite 6(`base './'`) · **Canvas 2D 직접 시각화**(차트 라이브러리 X) ·
ML **from scratch**(대형 신경망만 추후 TF.js 무료 검토) · 수식 필요 시 KaTeX(무료) ·
콘텐츠 **데이터 주도** · 배포 Vercel 정적 · 저장 localStorage · K-12~대학 안전 표현.

## 6. 제작 로드맵 (Phase)
- **Phase 0 · 학습 셸**: LessonEngine + 5스텝 루프 + 진척/퀴즈 엔진 + SimulatorShell 골격 + 홈(챕터 목록).
- **Phase 1 · CH0 입문**: 0.1~0.6 (개념·체험 위주, "선 맞추기" 체험 포함). ← 가장 먼저 "쉽고 재미" 체감.
- **Phase 2 · CH1 회귀**: 1.1~1.3 (시뮬 본격 — 선형회귀·경사하강·과적합).
- **Phase 3 · CH2 분류**, **Phase 4 · CH3 비지도**, **Phase 5 · CH4 신경망**, **Phase 6 · CH5 심화/윤리/수료**.
- **Phase 7 · 마감**: 프리셋, 강의 모드, 반응형/접근성, 배포.

레슨 "완료" 정의: 개념·체험·시뮬·퀴즈 모두 동작 · 진척 저장 · 누수 없음 · 한국어 친절 톤.
