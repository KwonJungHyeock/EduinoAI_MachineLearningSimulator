# 초기 컨셉 확정 사항

author: eduino · 확정 2026-10-15 (초기 컨셉 기획안 1~4 검토 후)

## 확정
| 항목 | 확정 내용 |
|---|---|
| 학습 주제 이름 | **기술 이름 그대로** — 이름만 봐도 무엇을 배우는지 알 수 있게 |
| 트랙 구성 | **공통 기초 + 6트랙**: 머신러닝 기초 / AI 영상처리 · 언어 모델 LLM · 음성 AI · 데이터 예측 AI · 피지컬 AI · 생성형 AI |
| 세계관 | **AI 미래도시** 하나 안에 **특화 지구** — 지구마다 그 기술이 쓰이는 현장 · 사건 · 스토리가 다르고, 큰 도시로 이어짐 |
| 트랙 전개 | 진입 → 기초 → 실습 → 알고리즘 체험 → 상황 해결 (차시 하나 안에서는 공통 양식 v2 6단계) |
| 모델 | **직접 구현**. 외부 AI API 없음. 작은 모델은 브라우저에서 학생이 직접 학습, 무거운 모델(CNN · 작은 생성 모델 · 작은 언어 모델)은 미리 학습한 가중치를 넣어 브라우저에서 실행 |
| 모션그래픽 | **추상 모션(데이터 · 신경망 · 파형 등 원리 표현)은 코드로 생성**, 장소 · 로봇 · 물건 그림은 렌더 · 3D 에셋만 |
| 디자인 톤 | 진입 · 세계관 화면은 시네마틱 다크 + 트랙 키 컬러 모션, 학습 화면은 밝은 레일(교실 가독성) |
| 기술 | React + Vite + TypeScript, Framer Motion(전환), Canvas 2D 생성형 모션, 3D는 react-three-fiber + three 0.165 예정 |
| 배포 | 웹 플랫폼. 글꼴 · 라이브러리 자체 번들(외부 CDN 없음 → 학교망 대응). file:// 더블클릭 요건은 없음 |
