# AI 로봇 타운 — 시제품 (파트 1: 골격 + 타운 지도)

author: eduino

학교망(오프라인·CDN 차단)을 전제로 한 단일 페이지 시제품입니다.
외부 라이브러리를 받지 않고, `index.html`을 **더블클릭(file://)** 해도 지도와 이름표가 뜹니다.

## 폴더 구성
```
ai-town/
  build.py          데이터(JSON)를 페이지에 끼워 index.html 생성 (화면 로직은 넣지 않음)
  tpl.html          페이지 틀(템플릿). 데이터 자리 표시자만 둠
  index.html        build.py 결과물. 배포·실행 대상 (직접 수정하지 말 것)
  src/
    styles.css      화면 스타일
    app.js          화면 전환·지도 이동/확대·저장 어댑터·EDDIE 안내 (모든 로직)
  data/
    map_hot.json    타운 지도 이름표 좌표·상태
  assets/           렌더 이미지·캐릭터 등 에셋 슬롯 (파일 없으면 빈 슬롯에 파일명 표시)
```

## 빌드
```
python3 build.py
```
`data/*.json` 을 읽어 `tpl.html` 의 데이터 자리에 넣고 `index.html` 을 만듭니다.
JSON 을 고쳤으면 다시 빌드하세요. (file:// 에서는 fetch 가 막히므로 데이터를 페이지에 직접 끼웁니다.)

## hot.json 형식 (직접 정함)
좌표는 **렌더 이미지 기준 0~1 비율**입니다. Blender 렌더를 이 형식에 맞춰 내보낼 예정입니다.

```jsonc
{
  "image": { "day": "assets/map_day.webp", "night": "assets/map_night.webp", "w": 2000, "h": 1250 },
  "hotspots": [
    { "id": "lab", "name": "로봇 연구소", "kind": "entry", "x": 0.50, "y": 0.74, "status": "open" }
  ]
}
```

| 필드 | 뜻 |
|---|---|
| `id` | 건물 식별자 (저장·진행도 키로 사용) |
| `name` | 화면에 보이는 이름 (이름표 텍스트) |
| `kind` | 종류: `entry`(연구소 입구) · `garage` · `plaza` · `building` · `expansion` |
| `x`, `y` | 이미지 기준 0~1 비율 좌표 (좌상단 0,0 / 우하단 1,1), 이름표 중심 |
| `status` | `open`(들어갈 수 있음) · `soon`(준비 중, 눌러도 안 들어감) |

**진행 상태(불 켜짐)** 는 hot.json 에 넣지 않고 저장값에서 계산합니다.
해당 건물의 단원을 완료하면 그 건물에 불이 켜집니다. (예: `lab` 은 `0-2` 완료 시)

## 이번 파트에서 여는 것
- 화면 4개(지도 · 건물 안 · 미션 · 차고)를 오가는 단일 페이지 **골격**
- 타운 지도: 낮/밤 전환, 끌어 이동, 1~4배 확대, 이름표 9개
- 열리는 건물: **로봇 연구소 · 로봇 차고** (나머지 7개는 `준비 중`)
- 첫 방문 안내 3단계(EDDIE): 타운 소개 → 내 로봇 받기 → 연구소로 이동
- 저장 어댑터 한 곳 (지금은 브라우저 저장소, 서버 연결 자리만 남김 / 하드삭제 없음·소프트삭제만)

건물 안(파트 2) · 미션 0-2(파트 3) · 차고 내부(파트 4) 는 자리만 둔 빈 화면입니다.

## 규칙 (항상 유지)
- 하드삭제 없음 — 소프트삭제만 (`save.js` 어댑터)
- 화면 수치는 코드 계산값만 (지어내지 않음)
- 비주얼은 에셋 슬롯만 — 코드로 그림을 그리지 않음. 파일이 없으면 빈 슬롯에 파일명 표시
- 코드 머리주석: `author: eduino` (프로젝트 이름은 넣지 않음)
