# 에셋 작업 가이드 (Playino : Escape Room)

> **워크플로우**
> 1. 클로드가 각 장면 **초안(절차적 placeholder)** 을 먼저 만든다. ← 지금 단계
> 2. 사장님이 슬롯 규격에 맞춰 **이미지(투명 PNG)** 를 제작해 `public/assets/` 에 저장.
> 3. "○○ 넣었어" 라고 알려주면, 클로드가 그 이미지를 보고 **씬에 배치·연출(글로우/그림자/애니)** 을 입힌다.
> 4. 이미지가 없으면 자동으로 절차적 폴백이 쓰이므로, **한 장씩 점진 교체** 가능.

## 폴더 구조
```
public/assets/
  characters/   # EDDIE 등 캐릭터
  backgrounds/  # 장면 배경(풀스크린)
  ui/           # 버튼/패널/아이콘 등 UI 파츠
  rooms/        # 미션 방별 소품/배경
```

## 공통 규칙
- **포맷**: PNG (투명 배경). 배경 슬롯만 불투명 가능.
- **해상도**: 게임 기준 해상도는 **1280×720**. 표의 권장 크기는 그 기준의 2배(레티나) 안전치.
- **여백/중심**: 캐릭터·소품은 캔버스 **중앙 정렬**, 불필요한 여백 최소화(클로드가 코드로 위치 잡음).
- **톤**: 다크 네이비~블랙 + 비상등 앰버/레드 포인트, EDDIE 눈빛(시그니처 청록 #6fffd6). 고어/위협 연출 금지(K-12).
- 파일명은 **정확히 아래대로**(소문자). 넣고 나서 알려주면 슬롯을 활성화한다.

## 방(미션) 소품은 추후
CH2 방을 만들 때 `rooms/<roomId>/...` 규격을 이 문서에 추가한다(예: `rooms/buzzer/console.png`).

## 슬롯 활성화(개발 메모)
`src/game/assets.js` 의 `ASSET_SLOTS` 에 `{ key, path }` 를 추가하면 Preload가 로드하고,
각 씬에서 `hasAsset(scene, key)` 로 분기해 이미지/폴백을 선택한다. (클로드가 이미지 수령 시 처리)
